# Dataset

The dataset used in this project is the **Telco Customer Churn dataset**.

The dataset was obtained from Kaggle and is **not included in this repository**.

### Download Instructions

1. Open the Kaggle dataset using the link below.
2. When downloading the dataset, select **all 21 columns** to obtain the complete dataset used in this project.
3. Download the CSV file.
4. Upload the CSV file to the Streamlit application when using the **Data Analysis** page.

**Source:** Kaggle

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The dataset was used for educational and machine learning project purposes.
